# Scout Game

Офлайн-игра про управление CS2-организацией: собирайте состав, изучайте рынок, тренируйте игроков и проводите команду через сезон.

## Запуск

```bash
npm install
npm start
```

## Windows EXE

На Windows после установки зависимостей выполните:

```bash
npm run dist
```

В папке `dist/` появятся установщик `Scout Game Setup.exe` и переносимая версия `.exe`. Для одной переносимой сборки используйте `npm run dist:portable`.

Данные сохраняются локально в браузерном хранилище. Кнопка «Новая карьера» очищает сохранение.

## Сборка в один клик

На Windows можно просто дважды нажать `build-exe.bat`. Скрипт проверит Node.js, установит зависимости и создаст установщик и portable-версию в `dist/`.
